# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes a resume and compares the candidate's skills with the skills required for a job.

## 📌 About the Project

The AI Resume Analyzer allows users to upload their resume and enter a job description. The application extracts skills from the resume, compares them with the required job skills, and displays the matching and missing skills.

## ✨ Features

- 📄 Upload resume
- 💼 Enter job description
- 🔍 Extract skills from resume
- 🎯 Compare resume skills with job requirements
- ✅ Display matched skills
- ❌ Display missing skills
- 📊 Calculate skill match percentage
- 🌐 Simple web-based interface
